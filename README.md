# LOL AD Coach Skill

一個以英雄聯盟 AD 玩家情境設計的 **AI 對話教練 Skill**。不是獨立 App、不是遊戲外掛，也沒有串接 Riot API 或自行訓練模型。

## 內容

- [SKILL.md](SKILL.md)：四種模式的選擇與回覆規則。
- [玩家設定範本](references/player-profile.md)：通用、無個人帳號資料的設定。
- [設計筆記](DESIGN-NOTES.md)：需求、AI 分工與限制。

## 四種模式

1. BP 急速：先給可執行選角，簡短說明原因和前期行動。
2. 對局即時：鎖角後分析兵線、技能窗口與團戰，避免再叫玩家換角。
3. 覆盤：把可見事實、推論與下次行動分開，聚焦少數高影響問題。
4. 研究：需要版本資料時查官方更新與統計，註明來源、時間與限制。

## 如何試用

可先閱讀 SKILL.md，將其作為你已授權 AI 助理的工作規格。支援 SKILL.md 的環境可按該平台的官方方式放入 skills 目錄，保留 references 相對位置。不同平台的安裝、圖片／影片和瀏覽能力不同，本 repository 不提供帳號連接或工具權限。

修改通用玩家範本，填入願意分享的偏好，再用以下問題試用：

> 我已鎖定燼，請先給前三波兵線與換血條件。看不到的技能冷卻和敵方打野位置不要猜。

## 技術與能力

Markdown、YAML front matter、Prompt／情境路由、證據與推論分離、簡短輸出約束。圖片分析與網頁研究依賴所用 AI 平台的能力；DeepLOL／OP.GG 是可能引用的公開資料來源，不是內建 API。

## 我的角色與 AI 分工

我提出遊戲情境、回覆偏好與實際使用回饋，AI 協助整理成可重用規格。這項作品呈現需求分析與 AI 工作流程設計，而非獨立開發完整軟體。

## 限制與公開範圍

公開版已移除私人玩家身分與帳號紀錄，改用通用範本。僅包含使用者自訂 Skill 與本次撰寫文件，不含平台內部規則或第三方程式框架。未量化驗證對勝率／段位的效果；建議可能受版本與辨識錯誤影響。沒有自動操作遊戲或保證上分功能。
