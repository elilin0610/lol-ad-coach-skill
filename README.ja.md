# LOL AD Coach Skill

[繁體中文](README.md) | [English](README.en.md) | **日本語**

『League of Legends』の ADC プレイヤーが直面する場面に合わせた **対話型 AI コーチの Skill** です。単体アプリやゲーム用アドオンではなく、Riot API との連携や独自モデルの学習も行っていません。

## 内容
- [SKILL.md](SKILL.md)：4つのモードの選び方と回答ルール。
- [プレイヤー設定テンプレート](references/player-profile.ja.md)：個人アカウント情報を含まない汎用テンプレート。
- [設計ノート](DESIGN-NOTES.ja.md)：要件、AI との役割分担、制約。

## 4つのモード
1. **ドラフト即答**：今すぐ選べるチャンピオンを先に挙げ、理由と序盤の動きを短く示します。
2. **試合中**：ピック確定後は、別のチャンピオンを勧めず、ウェーブ管理、スキルの隙、集団戦を扱います。
3. **振り返り**：確認できる事実、推測、次回の行動を分け、影響の大きい少数の課題に絞ります。
4. **調査**：パッチ固有の情報が必要なら、公式パッチノートや統計を調べ、出典、確認時点、制約を示します。

## 試し方
まず SKILL.md を読み、利用を許可した AI アシスタントの作業ルールとして使えます。SKILL.md 対応環境では、対象プラットフォームの公式手順で skills ディレクトリに配置し、references の相対位置を維持してください。インストール方法、画像・動画の対応、ブラウジング機能は環境によって異なります。このリポジトリがアカウント連携やツール権限を提供するわけではありません。

汎用テンプレートに共有してもよい好みを記入し、次のように質問できます。

> ジンはピック済みです。最初の3ウェーブの方針とダメージ交換の条件を先に教えてください。見えていないスキルのクールダウンや敵ジャングラーの位置は推測しないでください。

## 技術と機能
Markdown、YAML front matter、プロンプトと状況に応じた振り分け、根拠と推測の区別、出力を短くする制約を使用します。画像分析やウェブ調査は利用する AI プラットフォームに依存します。DeepLOL と OP.GG は参照し得る公開情報源で、組み込み API ではありません。

## 開発方法：Socratic Tutor を活用した段階的な学習
一度の生成で完成させるのではなく、**Socratic Tutor** Skill を使い、学習と議論を重ねながら段階的に開発しました。

Socratic Tutor は質問によって思考や理解を促す学習補助で、ゲームの助言を行う `lol-ad-coach` Skill とは別の役割です。ここで記録しているのは開発・学習方法であり、私が Socratic Tutor を開発したことや、その Skill にコード生成器、ゲームエンジン、Riot API 連携が含まれることを意味しません。

学習の全手順や能力評価は公開していないため、この説明は完全なソフトウェア開発を独力で行えるという主張ではありません。

## 私と AI の役割
私はゲーム内の状況、回答の好み、実際に使った感想を示し、AI はそれを再利用可能な仕様に整理しました。この作品が示すのは要件分析と AI ワークフロー設計であり、完全なソフトウェアを独力で開発したということではありません。

## 制約と公開範囲
公開版ではプレイヤー個人の身元とアカウント履歴を除き、汎用テンプレートに置き換えています。ユーザーが定義した Skill と今回作成した文書のみを含み、プラットフォーム内部のルールや第三者のコードフレームワークは含みません。勝率やランクへの効果は定量的に未検証で、バージョン差や認識誤りの影響を受けることがあります。ゲームを自動操作したり、ランク上昇を保証したりする機能はありません。
